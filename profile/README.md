# Simorq

Simorq builds practical and modern software for mental health teams.

## Goals

- Calm, fast, reliable clinic operations.
- One workspace for appointments, patients, payments, forms, messages, and history.
- Less admin. More focus on care.
- Clear visibility into revenue, workload, no-shows, and follow-up.
- Strong access control, traceability, and accountability.
- Persian-first products built around real clinic workflows.
